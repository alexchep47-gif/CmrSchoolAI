# CmrSchoolAI

**CmrSchoolAI** est le volet **intelligence artificielle** de l’écosystème **CMR School** — soutien scolaire pour le lycée camerounais (Maths, Physique, Chimie).

> Site public GitHub Pages : **[https://alexchep47-gif.github.io/CmrSchoolAI/](https://alexchep47-gif.github.io/CmrSchoolAI/)**

---

## Objectif

Proposer un point d’entrée clair pour l’IA CMR School :

- assistant de révision (Maths · Physique · Chimie)
- correction guidée via **photo d’exercice** sur Telegram
- lien vers le site, le bot et l’app mobile

Inspiré des parcours type **MAXA** (progression, quiz) et **Eduralis** (épreuves, photo → bot).
