Les modules fonctionnels sont isolés par niveau et prêts à être branchés sur les services sécurisés :

- `chat_tutor` : tuteur IA avec contexte de niveau
- `scan_homework` : capture et correction OCR
- `exam_generator` : épreuves et corrigés
- `library_by_level` : bibliothèque chiffrée hors-ligne
- `dashboard_progress` : progression, lacunes et recommandations
